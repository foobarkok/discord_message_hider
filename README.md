# Discord Message Hider

Discord Webで、**特定のメッセージだけを自分のブラウザ上で永続的に非表示**にするためのChromium拡張機能です。

通常の非表示メッセージは、デフォルトでは完全に非表示になります。設定を変更すると、代わりに`[非表示の発言]`というプレースホルダーを表示できます。

非表示にしたメッセージが別のメッセージから**引用・返信プレビューされた場合、その引用部分だけを`[非表示の発言]`へ置換**します。引用元以外の本文はそのまま表示します。

> **注意:** DiscordのWeb UIは内部DOM構造が変更される可能性があります。この拡張機能はDiscordのDOMを直接読むため、DiscordのUI更新によってメッセージ検出や引用検出が動かなくなる可能性があります。

## 主な機能

- Discordの個別メッセージを右クリックして非表示
- message IDを主キーとして非表示状態を永続保存
- 非表示にした時点の以下の情報を記録
  - メッセージID
  - チャンネルID
  - 当時のチャンネル名
  - サーバーID（取得できる場合）
  - 作者ID（取得できる場合）
  - 当時の作者名
  - メッセージ本文
  - 添付ファイルの名前・URL（取得できる場合）
  - 非表示にした日時
- 通常メッセージの表示方法を設定可能
  - 完全に非表示（デフォルト）
  - `[非表示の発言]`を表示
- 引用・返信プレビューは常に`[非表示の発言]`へ置換
- 非表示メッセージの一覧を専用管理ページで閲覧
- 本文・作者名・チャンネル名・IDで検索
- 新しい順 / 古い順 / チャンネル順 / 作者順にソート
- 個別解除・複数選択解除・全解除
- JSON形式でエクスポート / インポート
- インポートは既存データとのマージ方式

## 動作環境

- Chromium系ブラウザ
  - Google Chrome
  - Chromium
  - Microsoft Edge
  - その他、Manifest V3拡張機能に対応したChromium系ブラウザ
- Discord Web: `https://discord.com/channels/*`

このプロジェクトはManifest V3を使用しています。ChromeのStorage APIには拡張機能用の`storage.local`があり、拡張機能を削除するまではローカルに保存できます。現在のChromeでは`storage.local`の既定上限は10MBです。大量の履歴を保存する場合は、この上限を意識してください。([Chrome Extensions: storage API](https://developer.chrome.com/docs/extensions/reference/api/storage))

## インストール（開発版）

Chrome / Chromium / Edgeなどでは、ビルドやパッケージ化をしなくても**パッケージ化されていない拡張機能**として読み込めます。

1. このリポジトリをダウンロードまたは`git clone`します。
2. Chromium系ブラウザで`chrome://extensions`（Edgeなら`edge://extensions`）を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. このリポジトリのルートディレクトリを選択します。
6. `Discord Message Hider`が一覧に表示されれば読み込み完了です。

ソースを変更した場合は、拡張機能管理ページの**再読み込み**ボタンを押してください。

## 基本的な使い方

### メッセージを非表示にする

1. Discord Webでチャンネルを開きます。
2. 非表示にしたいメッセージの上で右クリックします。
3. 拡張機能が表示する「このメッセージを非表示」を選択します。
4. メッセージが非表示になり、message IDをキーとして保存されます。

通常モードのデフォルトは完全非表示です。

### 表示方法を変える

拡張機能アイコン → 「非表示メッセージを管理」から管理ページを開くか、拡張機能ポップアップで切り替えられます。

- **完全に非表示**: メッセージ自体を表示しません。
- **`[非表示の発言]`と表示**: メッセージがあった位置にプレースホルダーを表示します。

この設定は通常メッセージにのみ適用されます。引用・返信プレビュー内の非表示メッセージは常にプレースホルダーになります。

### 非表示を解除する

プレースホルダーモードでは、Discord上の対象メッセージを右クリックして「このメッセージの非表示を解除」を選択できます。

完全に非表示モードでは対象メッセージ自体がDOM上で表示されないため、管理ページから対象の「解除」ボタンを押してください。

## 管理ページ

拡張機能アイコンから「非表示メッセージを管理」を開くと、過去に非表示にしたメッセージを一覧で確認できます。

各項目には、可能な範囲で以下が表示されます。

- 非表示にした時点のチャンネル名
- 非表示にした時点の作者名
- 非表示にした日時
- 保存した本文
- 添付ファイルの名前
- message ID

検索欄では本文、作者名、チャンネル名、IDを検索できます。

## JSONエクスポート / インポート

管理ページの「JSONをエクスポート」で、現在の設定と非表示メッセージ一覧をJSONとして保存できます。

例:

```json
{
  "version": 1,
  "settings": {
    "hiddenMessageDisplay": "none"
  },
  "messages": {
    "123456789012345678": {
      "id": "123456789012345678",
      "channelId": "234567890123456789",
      "channelName": "雑談",
      "guildId": "345678901234567890",
      "authorId": "456789012345678901",
      "authorName": "example",
      "content": "保存されたメッセージ本文",
      "attachments": [],
      "hiddenAt": 1790650000000
    }
  }
}
```

別のPCへ移行するときは、元のPCでJSONをエクスポートして、新しいPCの拡張機能管理ページでこの拡張を読み込み、管理ページからJSONをインポートしてください。

インポートは**現在のデータへマージ**します。同じmessage IDが存在する場合は、インポートしたレコードで置き換えられます。

## テスト手順

Discordの本番アカウントでテストする前に、**自分だけが参加しているテスト用サーバーやテスト用チャンネル**で確認することをおすすめします。

### 1. 拡張機能が読み込めるか

- `chrome://extensions`を開く
- デベロッパーモードを有効化
- 「パッケージ化されていない拡張機能を読み込む」からリポジトリを選択
- エラーが表示されていないことを確認

### 2. 個別非表示

テスト用チャンネルに複数のメッセージを用意し、1件を右クリックして非表示にします。

確認項目:

- 選択した1件だけが非表示になる
- 前後のメッセージは消えない
- チャンネル移動後に元のチャンネルへ戻っても非表示が維持される
- ページをリロードしても非表示が維持される
- DiscordのInfinite Scrollで一度DOMから外れて再生成されたあとも非表示になる

### 3. プレースホルダーモード

管理ページまたは拡張機能ポップアップで「`[非表示の発言]`と表示」を選びます。

確認項目:

- 非表示メッセージの位置に`[非表示の発言]`が表示される
- 設定を「完全に非表示」に戻すと、その場で消える
- ページをリロードしても設定が維持される

### 4. 引用・返信プレビュー

1件のメッセージを非表示にします。

そのメッセージを返信または引用したメッセージを同じチャンネルに用意します。

確認項目:

- 引用された元メッセージの内容だけが`[非表示の発言]`になる
- 引用した側の通常本文は表示される
- 非表示メッセージそのものをプレースホルダー表示にする設定にしても、引用部分は常に`[非表示の発言]`になる
- 非表示を解除すると、Discord側の通常表示へ戻る

### 5. 管理ページ

非表示メッセージを数件作り、管理ページを開きます。

確認項目:

- 全件が一覧に表示される
- チャンネル名・作者名・本文・日時が記録される
- 検索が機能する
- ソートが機能する
- 個別解除が機能する
- 複数選択して解除できる
- 全解除の確認ダイアログが出る

### 6. JSON移行

1. PC Aで数件非表示にする
2. JSONをエクスポートする
3. PC Bの拡張機能へJSONをインポートする
4. PC Bで同じmessage IDのメッセージが非表示になることを確認する
5. 管理ページで記録内容が表示されることを確認する

## 開発時のデバッグ

### 拡張機能側

`chrome://extensions`で対象拡張の「Service Worker」を開くと、バックグラウンド側のコンソールを確認できます。

### Discordページ側

Discordの開発者ツールを開き、Consoleで以下を確認します。

```text
Discord Message Hider init failed
Could not hide message
Could not unhide message
```

などのエラーが出ていないか確認してください。

### DOM検出の確認

Discordのメッセージには、現在のWeb UIでも`chat-messages-...`や`message-content-...`というID形式が使われる実例があります。ただし、これらはDiscord公開APIとして保証されたDOM仕様ではありません。この拡張では複数の候補を試して検出するようにしています。

Discord API上のメッセージ自体は一意なsnowflake形式の`id`を持ち、返信などには`message_reference.message_id`が使われます。そのため、保存キーは**メッセージ本文やユーザー名ではなくmessage ID**にしています。

参考:

- [Discord API - Message Resource](https://github.com/discord/discord-api-docs/blob/main/developers/resources/message.mdx)
- [Chrome Extensions - storage API](https://developer.chrome.com/docs/extensions/reference/api/storage)
- [Chrome Extensions - Manifest](https://developer.chrome.com/docs/extensions/reference/manifest)

## 既知の制約

### DiscordのDOM変更

この拡張はDiscordのDOMを直接解析するため、Discord側のCSS class名・DOM構造・属性・引用UIが変更されると検出に失敗する可能性があります。

そのため、Discord更新後に以下を重点的に確認してください。

- 通常メッセージのmessage ID取得
- メッセージ本文取得
- チャンネル名取得
- 引用元message ID取得
- 右クリックメニュー表示

### 引用検出

引用・返信プレビューのmessage IDを、リンク・`message-content-*` ID・data属性など複数の方法で推測します。DiscordがUIを変更した場合、引用部分だけを置換できなくなる可能性があります。

### 記録できる本文

テキスト本文はDiscord上のメッセージ本文DOMから保存します。埋め込みコンテンツの完全な内部データや、添付ファイル本体そのものは保存しません。添付ファイルについては取得できた名前・URLを保存します。

### 削除済みメッセージ

この拡張が保存しているのは**ブラウザ上の非表示ルールと当時のスナップショット**です。Discord上のメッセージを削除・編集したりする機能はありません。

### ストレージ

非表示履歴はChromeの`storage.local`に保存します。Chromeの現行ドキュメントでは既定容量は10MBです。大量の全文履歴や添付URLを長期間保存する用途では容量に注意してください。

## 設計方針

この拡張は、Discord APIへログイン情報を渡したり、メッセージの送信・削除・編集を行ったりせず、**Discord Webページに表示されているDOMだけをローカルで変更する**方針です。

保存されたメッセージ本文は、この拡張の管理画面で確認するためにローカルへ記録されます。JSONエクスポートを行った場合、そのファイルにも本文が含まれるため、共有・公開には注意してください。
